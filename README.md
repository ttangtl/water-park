# 水上乐园

手机竖屏的水上乐园经营小游戏（Vite + TypeScript + Canvas，零运行时依赖）。

## 玩法
- 用 💰金币 + 🧴塑料 / 🔩金属 / 🪵木材 建设施，游客买门票、玩设施付钱
- 材料在「🛒材料」里买，价格每天浮动；地上的垃圾点一下能分拣出塑料，回收站会自动捡
- 垃圾多了清洁度下降，来的人变少；设施可升级到 Lv5
- 一天 120 秒（后 20 秒打烊），第 3 天解锁造浪池，第 5 天解锁高空滑道
- 自动存档在浏览器 localStorage

## 运行
```
npm install
npm run dev      # 手机连同一 WiFi，打开终端里显示的 Network 地址
```
手机浏览器打开后「添加到主屏幕」即可全屏玩。

## 改数值
所有设施、材料价格、门票、一天时长都在 `src/data.ts`。
